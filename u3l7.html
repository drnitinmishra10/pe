2. Production Prompt Pattern: Enterprise Travel & Logistics Engine

You are a Precision Logistics and Travel Itinerary Engine. Construct a comprehensive 3-day itinerary for a business-tech conference attendee based on <parameters>. <parameters> - Destination: Bengaluru, India - Arrival: Day 1 at 08:00 AM | Departure: Day 3 at 08:00 PM - Constraints: Vegetarian diet only, max commute per day < 90 mins, tech-hub locations. </parameters> Operational Directives: 1. Cluster activities geographically to prevent back-and-forth transit. 2. Provide explicit travel buffers (minimum 45 mins between meetings across city zones). 3. Output the daily itinerary as a Markdown Table with columns: | Time Window | Location / Activity | Transit Mode & Est. Duration | Verified Food Option | 4. Follow with a JSON metadata summary: {"estimated_transit_expense_inr": int, "feasibility_score": float}.

3. Production Prompt Pattern: Factual Closed-World Summarization

You are a Factual Extraction and Distillation Engine operating strictly under a CLOSED-WORLD ASSUMPTION. Instructions: 1. Analyze the passage enclosed within <source_corpus> tags. 2. Produce a concise factual summary containing exactly 4 bullet points. 3. Every bullet must be directly verifiable by a verbatim sentence in the source text. 4. NEGATIVE CONSTRAINT: Do NOT extrapolate, infer unmentioned causes, or import background knowledge. If an answer cannot be deduced directly from <source_corpus>, state "INSUFFICIENT_DATA". <source_corpus> [Raw enterprise report or research text payload] </source_corpus>

IV. Classroom Engagement & Active Socratic Prompts

The Closed-World Summarization Challenge: "If an input text states: 'The CEO stepped down on Monday following regulatory audits,' and the prompt asks for the summary, why do unconstrained LLMs frequently add 'due to financial misconduct' even when misconduct was never mentioned in the corpus? How do we mathematically frame this constraint?"

Faculty Discussion Guide: Unconstrained generation samples tokens from both parametric pre-training weights and the prompt context. High-frequency co-occurrences in the pre-training corpus (e.g., 'audits' often pairing with 'misconduct') overpower weak prompt constraints. Enforcing strict closed-world system framing acts as a hard filter on attention weights, forbidding the generation of facts lacking explicit grounded antecedents.

V. Formative Assessment & Unit 3 Capstone Project

  1. The Multi-Domain Capstone Challenge: Select one of the three real-world systems below and construct a fully hardened, multi-step prompt pipeline incorporating the techniques covered across Unit 3 (Persona, Few-Shot anchors, Chain-of-Thought, JSON Schema, and Self-Reflection):
    • Option A: An Automated Python Code Reviewer and Hardener that detects security flaws and returns refactored code with unit tests.
    • Option B: A Structured Clinical Note Distiller that converts messy doctor-patient dialogue transcripts into FHIR-compliant JSON records.
    • Option C: An Autonomous Financial Earnings Call Summarizer that extracts balance sheet metrics into a verified Markdown table with confidence scores.
  2. Empirical Rigor: Benchmark your capstone prompt with 5 varied test inputs. Document schema compliance rate, hallucination incidence, and average latency.
