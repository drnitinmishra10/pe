Prompt Chaining

Class Notes | Generative AI & Prompt Engineering

1. Introduction

Prompt Chaining is a prompting technique in which a complex task is divided into a sequence of smaller prompts. The output produced by one prompt is passed to the next prompt as its input.

Instead of asking an AI system to complete a large task in one step, we guide it through several connected steps. This gives the user greater control over the reasoning process, intermediate outputs, and final result.

3. Why Use Prompt Chaining?

  • Breaks complex problems into manageable steps.
  • Improves consistency and quality of the final response.
  • Makes intermediate results easier to inspect and correct.
  • Allows different prompts to perform different subtasks.
  • Provides better control over the format and content of the final output.
  • Useful for research, education, coding, data analysis, and content creation.

4. Important Principles

  1. Define the goal: Clearly identify what the complete workflow must produce.
  2. Divide the task: Separate the main task into logical subtasks.
  3. Connect outputs: Use the result of one step as the context for the next.
  4. Validate intermediate results: Check important outputs before continuing.
  5. Specify the final format: Tell the final prompt exactly how the answer should be presented.

5. Example 1 — Research Article Summary

Goal

Convert a long research article into a concise academic summary.

Chain

Prompt 1: Read the research article and identify its research problem, objectives, methodology, dataset, and major findings.
Output 1: A structured list containing the problem, objectives, methodology, dataset, and findings.
Prompt 2: Using the extracted information, identify the three most important contributions of the research.
Output 2: Three clearly stated research contributions.
Prompt 3: Using the previous outputs, write a 200-word academic summary of the research article. Use formal language and include the research problem, methodology, key findings, and contribution.

Final result: A focused academic summary produced through several controlled steps.

6. Example 2 — Creating a Python Program

Goal

Develop a Python program for analysing student marks.

Prompt 1: Design the logic for a Python program that accepts student marks and calculates total, average, grade, and pass/fail status.
Output 1: Algorithm / program logic and required calculations.
Prompt 2: Convert the approved logic into clean Python code. Use functions, meaningful variable names, and basic input validation.
Output 2: Python implementation.
Prompt 3: Test the Python code using at least five different student-mark cases. Identify any errors and improve the code if required.
Output 3: Test results and corrected Python program.

Final result: A tested and refined Python program rather than an unverified one-shot response.

7. Advantages

  • Better control: Each stage has a clearly defined purpose.
  • Error detection: Problems can be found at the intermediate stage.
  • Higher reliability: Complex tasks are handled step by step.
  • Reusability: Individual prompts can often be reused in other workflows.
  • Flexible output: Each stage can transform information into a different format.

8. Limitations

  • A mistake in an early step can affect later outputs.
  • Long chains may require more time and token usage.
  • Too many unnecessary steps can make a workflow complicated.
  • Intermediate outputs should be checked when accuracy is important.
Key Point:
Prompt chaining means “divide → process → pass the output → process again → combine into the final result.”
Exam Definition:
Prompt chaining is a technique of dividing a complex AI task into a sequence of connected prompts, where the output of one prompt serves as input or context for the next prompt.

9. Quick Revision

  • One-shot prompting: One main prompt → one final response.
  • Prompt chaining: Multiple connected prompts → intermediate outputs → final response.
  • Main purpose: Improve control, structure, reliability, and quality.
