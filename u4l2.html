Advanced Prompting Techniques

Strategic Role-Playing • ReAct • Iterative Self-Refinement

Part A — Strategic Role-Playing

Strategic Role-Playing is a prompting technique in which the AI is assigned a specific professional role, perspective, expertise, or stakeholder position so that it can respond according to the goals, knowledge, responsibilities, and decision criteria associated with that role.

Basic Structure

Define Role
→
Set Goal
→
Provide Context
→
Set Constraints
→
Generate Response

Key Elements

  • Role: Specify who the AI should act as.
  • Objective: Clearly state what the role must accomplish.
  • Context: Provide relevant background information.
  • Constraints: Define audience, tone, scope, or rules.
  • Output format: Specify how the response should be presented.

Example 1 — AI as a Research Reviewer

Prompt: Act as a senior computer science research reviewer. Review the following research abstract for novelty, clarity, methodology, research gap, and potential weaknesses. Give your feedback in five sections and provide three specific suggestions for improvement.

Result: The AI evaluates the abstract from the perspective of a research reviewer rather than simply summarising it.

Example 2 — AI as an Academic Advisor

Prompt: Act as an experienced academic advisor. A second-year CSE student wants to learn AI and prepare for a research project. Design a 12-week learning plan covering Python, machine learning, deep learning, datasets, evaluation, and research-paper reading. Include weekly objectives, activities, and expected outcomes.

Result: The role guides the AI toward practical academic planning and mentoring.

Assignment — Strategic Role-Playing

Problem 1 — Industry Expert

Create a prompt that makes the AI act as a senior industry expert and evaluate whether a proposed AI product is technically and commercially feasible.

Problem 2 — Faculty Mentor

Create a prompt that makes the AI act as a university faculty mentor and prepare a one-semester improvement plan for a student who is weak in programming.

Problem 3 — Project Manager

Create a prompt that makes the AI act as a project manager and convert a software project idea into tasks, milestones, risks, dependencies, and deliverables.

Submission: Include the role, objective, context, constraints, prompt, and expected output format.

Part B — ReAct

ReAct stands for Reasoning and Acting. It is a prompting approach in which an AI system combines reasoning about a task with actions such as searching for information, using tools, checking data, or performing calculations, then uses the results of those actions to continue the task.

Basic Concept

Question
→
Reason
→
Act / Use Tool
→
Observe Result
→
Continue
→
Answer
Important: In practical AI systems, the internal reasoning process should not be treated as something that must be exposed to the user. The useful idea is the controlled cycle of deciding what action is needed, performing the action, observing the result, and using that result to continue.

Where ReAct is Useful

  • Web or document research
  • Data analysis and calculations
  • Tool-assisted problem solving
  • Information retrieval
  • Multi-step technical tasks

Example 1 — Research with a Web Search

Prompt: Find recent research on AI-based skin disease diagnosis. For each useful source, identify the dataset, model, major finding, and limitation. Use the collected evidence to prepare a comparison table and identify two research gaps.

ReAct-style workflow: identify what information is needed → search for sources → inspect results → extract evidence → compare findings → formulate research gaps.

Example 2 — Data Analysis

Prompt: Analyse the supplied student dataset. First inspect the columns and data types. Then calculate descriptive statistics, identify missing values, analyse performance patterns, and finally generate three actionable recommendations based on the evidence.

ReAct-style workflow: inspect data → perform calculation → observe result → decide next analysis → validate findings → produce recommendations.

Assignment — ReAct

Problem 1 — Current Technology Research

Design a ReAct-style workflow for finding and comparing three recent AI technologies. Specify what should be searched, what evidence should be extracted, and how the final comparison should be produced.

Problem 2 — Dataset Investigation

Design a ReAct-style workflow for analysing a dataset containing student attendance and marks. The workflow must inspect the data, calculate relevant statistics, identify patterns, and produce conclusions.

Problem 3 — Troubleshooting

Design a ReAct-style prompt for diagnosing a Python program that produces an error. The workflow should inspect the error, examine the relevant code, identify the likely cause, propose a fix, and validate the solution.

Submission: Draw the Reason → Act → Observe cycle and describe the purpose of each action.

Part C — Iterative Self-Refinement

Iterative Self-Refinement is a prompting technique in which an AI first produces a draft, evaluates that draft against explicit criteria, identifies weaknesses, and then generates an improved version. The process can be repeated for further improvement.

Basic Workflow

Draft
→
Evaluate
→
Identify Weaknesses
→
Revise
→
Final Output

Key Principles

  • Define clear evaluation criteria before refinement.
  • Ask for specific weaknesses rather than vague criticism.
  • Revise using the identified issues.
  • Compare the revised output with the original requirements.
  • Repeat only when additional refinement provides meaningful benefit.

Example 1 — Improving an Assignment Answer

Prompt 1: Write a 300-word answer explaining supervised learning for undergraduate CSE students.
Prompt 2: Evaluate the answer for technical accuracy, clarity, examples, structure, and suitability for undergraduate students. List specific weaknesses.
Prompt 3: Rewrite the answer by fixing every identified weakness while preserving the correct information and keeping the answer within 300 words.

Result: The second version is improved using explicit evaluation criteria rather than being accepted as the first draft.

Example 2 — Improving a Research Abstract

Prompt 1: Write a research abstract for a deep-learning system for skin disease classification.
Prompt 2: Critically evaluate the abstract for problem clarity, research gap, methodology, results, novelty, and academic language. Identify missing or weak elements.
Prompt 3: Rewrite the abstract using the evaluation feedback. Make it concise, academically appropriate, and logically structured without inventing experimental results.

Result: The abstract passes through a controlled draft → evaluation → revision cycle.

Assignment — Iterative Self-Refinement

Problem 1 — Improve an Explanation

Create a three-step self-refinement chain to improve an AI-generated explanation of “Machine Learning” for Class 10 students. Define at least four evaluation criteria.

Problem 2 — Improve a Presentation

Create an iterative refinement prompt chain for a 10-slide presentation on “Generative AI”. The chain should evaluate structure, accuracy, audience suitability, and visual clarity before producing the final version.

Problem 3 — Improve Code

Create a self-refinement chain for a Python program that calculates student grades. The AI must review the code for correctness, readability, edge cases, and input validation, then produce an improved version.

Submission: Show the original draft, evaluation criteria, identified weaknesses, revised output, and a short comparison between the two versions.

Quick Comparison

Technique Main Idea Best Used For
Strategic Role-Playing Give the AI a specific role, perspective, expertise, and objective. Expert advice, mentoring, reviewing, planning, stakeholder analysis.
ReAct Combine task reasoning with actions/tools and observations. Research, retrieval, calculations, data analysis, troubleshooting.
Iterative Self-Refinement Generate, evaluate, identify weaknesses, and improve repeatedly. Writing, code, research drafts, presentations, quality improvement.
Exam Tip:
Strategic Role-Playing changes the perspective of the AI; ReAct connects reasoning with actions and observations; Iterative Self-Refinement focuses on drafting, evaluation, and improvement. These techniques can also be combined in a single advanced prompting workflow.

Final Revision

  • Strategic Role-Playing: “Who should the AI act as?”
  • ReAct: “What action should the AI take, what result did it observe, and what should happen next?”
  • Iterative Self-Refinement: “How can the current output be evaluated and improved?”
