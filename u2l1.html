✍️ What is a Prompt?

Definition:
A prompt is the text, instructions, questions, examples or other input provided to a Generative AI system to guide the response or output it produces.

Simple Definition

A prompt is the way we communicate our intention, task and expectations to an AI system.

Think of a Prompt as an Instruction

When we ask a person to perform a task, the quality of the result often depends on how clearly we explain what we want. The same principle applies when interacting with an AI system.

Important: A prompt does not guarantee a correct answer. A clear prompt generally helps the model better understand the intended task and produce a more relevant response.

Key Characteristics of a Good Prompt

  • Clarity: The instruction should be easy to understand.
  • Context: Important background information should be provided.
  • Specificity: The task and expectations should be clear.
  • Constraints: Length, audience, scope or limitations can be specified.
  • Output Format: The desired form of the answer can be mentioned.

🧩 Basic Anatomy of a Prompt

A useful beginner-level prompt can often be understood using the following components:

Component Purpose Example
Task What should the AI do? Explain machine learning.
Context What background does the AI need? The learners are first-year B.Tech students.
Audience Who is the output for? Beginner engineering students.
Constraints What limitations should be followed? Use simple language and keep it under 200 words.
Output Format How should the answer be presented? Use headings and bullet points.
Beginner Formula:

Effective Prompt = Task + Context + Audience + Constraints + Output Format

⚡ Casual Queries vs Structured Prompts

Parameter Casual Query Structured Prompt
Clarity Vague or informal Specific and intentional
Context Little or no context Relevant background is provided
Audience Usually unspecified Target audience is identified
Constraints Usually missing Word limit, scope or conditions may be specified
Output Format Usually unspecified Required structure or format is mentioned
Example "Write about AI." "Explain Artificial Intelligence to first-year B.Tech students in simple language using five bullet points and one real-world example."

The Core Difference

  • Casual Query: Leaves more interpretation to the AI.
  • Structured Prompt: Reduces ambiguity by clearly defining the task and expectations.
  • Important: A longer prompt is not automatically a better prompt. Relevance and clarity matter more than unnecessary detail.

🔄 Before and After: Improving a Prompt

Example 1: Programming

Weak Prompt:
"Explain Python."
Improved Prompt:
"Explain Python programming to first-year B.Tech students who are new to programming. Cover variables, data types and conditional statements using simple language and short examples. Keep the explanation within 300 words."

Example 2: Data Science

Weak Prompt:
"Explain data visualization."
Improved Prompt:
"Explain data visualization to undergraduate students studying Data Science. Define the concept, explain why it is useful, and give three examples of commonly used charts. Present the answer using headings and bullet points."

What Changed?

  • The task became more specific.
  • The audience was identified.
  • Relevant context was added.
  • Scope and output requirements were specified.

💡 Why is Prompt Design Important?

  • Improves Relevance: Clear instructions help the model focus on the intended task.
  • Reduces Ambiguity: Specific prompts leave less room for different interpretations.
  • Saves Time: Better initial instructions can reduce repeated revisions.
  • Controls Output: Users can specify audience, tone, length and structure.
  • Improves Consistency: Reusable prompt structures can produce more consistent results across similar tasks.
  • Supports Complex Tasks: Well-organized instructions can help break complicated tasks into manageable steps.
Remember: Prompt engineering improves the quality and usefulness of interaction with an AI model, but it cannot eliminate model errors, hallucinations or factual inaccuracies.

🚫 Common Problems with Poor Prompts

Problem Example Possible Effect
Too vague "Tell me about computers." Very broad response
Missing context "Explain recursion." Difficulty choosing the appropriate depth
Ambiguous instruction "Make it professional." Different interpretations of "professional"
No output requirement "Explain databases." Unpredictable structure or length
Too many unrelated instructions Multiple conflicting requirements Possible inconsistency or incomplete response

✅ Basic Best Practices for Prompt Writing

  1. State the task clearly.
  2. Provide only relevant context.
  3. Specify the target audience when it matters.
  4. Mention important constraints such as length or scope.
  5. Specify the desired output format.
  6. Use simple and unambiguous language.
  7. Review and refine the prompt based on the output.
  8. Verify important facts independently, especially for academic, technical or high-stakes tasks.

🎓 Classroom Activity

  1. Start with the simple prompt: "Explain sorting algorithms."
  2. Ask students to improve the prompt by adding: audience, context, word limit and output format.
  3. Example improved prompt: "Explain sorting algorithms to first-year B.Tech students. Compare Bubble Sort, Selection Sort and Insertion Sort. Use simple language, a comparison table and one practical example. Keep the answer within 350 words."
  4. Enter both prompts into an LLM tool.
  5. Compare the outputs and identify what changed.
  6. Ask students: Which part of the improved prompt made the biggest difference?

🧠 Think Like a Prompt Engineer

Before submitting a prompt, ask yourself:

1. What do I want?
Clearly identify the task.
2. Who is the output for?
Specify the audience when relevant.
3. What context does the AI need?
Provide important background information.
4. What constraints should be followed?
Mention length, scope, tone or limitations.
5. What should the final output look like?
Specify format such as table, bullets, paragraph, code or JSON.

📝 Assignment

  2. Write three prompts for the same topic for:
    • A middle school student
    • A college student
    • An IT professional
  3. For each prompt, include: Task, Context, Audience and Output Format.
  4. Generate responses using an LLM and compare how the outputs differ.
  5. Write a short observation of approximately 100 words explaining how the prompt influenced the response.

📌 Key Takeaways

  • A prompt is the input or instruction used to guide a Generative AI system.
  • Clear prompts generally improve the relevance and usefulness of AI-generated responses.
  • A useful beginner prompt can be structured around: Task + Context + Audience + Constraints + Output Format.
  • A longer prompt is not necessarily a better prompt; relevant and clear instructions are more important.
  • Prompt engineering is an iterative process: write, test, evaluate and refine.
  • Even a well-written prompt does not guarantee factual correctness. Important information should be verified.
