✨ Core Principles of Good Prompt Writing

The Quality Principle:
The quality of AI output is directly proportional to the clarity, context, and structural precision of the input prompt.

1. Be Clear and Specific

Avoid broad requests. State exactly what topic to cover, the depth required, and key points to emphasize.

2. Use Positive Directives

Focus on instructing the model on what to do rather than solely on what not to do.

3. Leverage Delimiters

Use clear punctuation (triple quotes """, XML tags <text>, or backticks ```) to separate instructions from source data.

4. Provide In-Context Examples (Few-Shot Prompting)

Demonstrate desired input-output pairs to guide format, tone, and reasoning style.

⚡ Few-Shot Prompting in Practice

Zero-Shot (No Examples):
"Classify the sentiment of this feedback: 'The application UI is clean but crashes often.' Response:"
Few-Shot (With Examples):
"Classify the sentiment into Positive, Negative, or Mixed.

Text: 'The battery life is amazing.' → Sentiment: Positive
Text: 'The payment failed twice.' → Sentiment: Negative
Text: 'The application UI is clean but crashes often.' → Sentiment: Mixed"

🛠️ Common Pitfalls vs Best Practices

Common Pitfall Why It Fails Best Practice Solution
Ambiguous Language Model makes assumptions leading to generic answers. Specify audience, word limit, tone, and key focus areas explicitly.
Overloading Directives Confuses the model with conflicting instructions. Break complex tasks into step-by-step sequential prompts.
Unformatted Source Data Model struggles to distinguish commands from input text. Isolate input text using delimiters like triple quotes or section headers.
Assuming World Knowledge Can cause hallucinations on specific or modern context. Provide explicit reference text within the prompt context.

📌 Lecture Summary

  • Good prompts rely on clarity, directness, and proper formatting techniques.
  • Few-Shot prompting guides LLMs by demonstrating expected input-output patterns.
  • Delimiters help separate task instructions from input data, avoiding misinterpretations.
  • Iterative prompt refining is necessary to eliminate model hallucinations and vagueness.
