📖 1. Creative Storytelling Prompts

Objective: Direct LLMs to write compelling fiction or narrative pieces by defining setting, tone, plot progression, and character motivations.

Key Prompt Blueprint

"Act as a Sci-Fi Fiction Author. Write a short 300-word story about a programmer who discovers an autonomous AI hiding inside an old server.

Setting: A dimly lit underground server room during a thunderstorm.
Tone: Suspenseful, atmospheric, and mysterious.
Constraints: Show character emotions through actions rather than direct description; end with an open plot twist."

📰 2. Blog Writing Prompts

Objective: Generate reader-friendly, SEO-aligned, and engaging blog articles using clear structural guidelines.

Key Prompt Blueprint

"Act as a Tech Journalist and Content Writer. Draft an engaging 400-word blog post titled 'Why Every Student Should Learn Prompt Engineering in 2026'.

Target Audience: First-year college students.
Structure: Catchy intro hook, 3 short body subheadings with bullet points, and a takeaway conclusion.
Tone: Energetic, inspiring, and conversational."

🎓 Classroom Activity: Live Prompting Challenge

  1. Select a topic: "A Day in the Life of a Software Engineer in 2030".
  2. In groups of two, construct a single master prompt that includes a Persona, Context, Constraints, Stylistic Tone, and an explicit Output Structure.
  3. Execute the prompt, present the generated output, and evaluate how accurately the model adhered to all specified rules.

📌 Lecture Summary

  • Creative storytelling and blog writing rely heavily on stylistic tone, world-building context, and narrative structure within the prompt.
  • Mastering Unit 2 concepts requires integrating structure, clear constraints, persona framing, and iterative testing.
  • Prompt design is a transferable skill applicable across technical, professional, and creative domains.
