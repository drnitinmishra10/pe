Learning Objectives

By the end of this lecture, students should be able to:

  • Explain how text, images, audio, and video can be used together in a workflow.

  • Evaluate quality, consistency, accuracy, accessibility, privacy, and responsible use across outputs.

1. What Is Multimodal AI?

Multimodal AI refers to AI systems that can process, relate, or generate more than one kind of information, such as text, images, audio, and video. A text-only system works primarily with language, while a multimodal system may answer questions about an image, analyse spoken audio, or combine visual and textual information.

Multimodal capability varies by tool. Some systems accept multiple input types but generate only text; others can produce images, speech, or video. Always check which inputs, outputs, and file formats a particular tool supports.

3. Why Combine AI Tools?

A complex task often requires more than one kind of output. For example, preparing a student workshop resource may involve writing a plan, creating a poster, building slides, preparing narration, and producing a short video. Separate tools can help with individual steps, while a clear workflow keeps the content consistent.

  • Efficiency: Reuse verified content instead of starting every asset from scratch.
  • Consistency: Keep the same terminology, audience, key messages, and visual direction across formats.
  • Accessibility: Convert written content into audio or provide captions and text alternatives.
  • Adaptability: Repurpose a long explanation into slides, an infographic, or a short script.
  • Quality control: Check facts at each stage before passing information to another tool.

4. Prompt Chaining

Prompt chaining is a workflow in which the output of one AI task is reviewed and then used as input for a later task. The chain should contain checkpoints: do not automatically pass an unverified result into every later step.

  1. Task 1 — Research or source extraction: Gather information from supplied or reliable sources.
  2. Task 2 — Structure: Turn verified information into an outline or content brief.
  3. Task 3 — Generate assets: Create a presentation outline, image prompt, narration script, or infographic plan.
  4. Task 4 — Adapt: Convert approved content into another format, such as captions or a short video script.
  5. Task 5 — Review: Check all assets against the approved source and correct inconsistencies.
Key principle: Prompt chaining improves organisation, but errors can also propagate. Verify important facts and claims before each hand-off.

6. Example Prompt Chain

Prompt 1: Create a content brief

Create a content brief for a 10-minute introductory session on responsible
AI use for undergraduate engineering students.
Include three learning objectives, five key concepts, two short examples,
and one class activity. Do not invent statistics or references. Flag any
claims that require external verification.

Prompt 2: Convert the approved brief into slides

Using only the approved content brief below, create a 6-slide presentation
outline. For each slide provide a key-message title, up to four concise
bullets, one visual suggestion, and brief speaker notes.
Do not add unsupported facts or change the learning objectives.
[Paste the reviewed brief here]

Prompt 3: Create a poster concept

Using the same approved message and audience, create a clean poster
concept for “Responsible AI Use for Engineering Students”.
Use a clear title area, three short principles, simple visual symbols,
high contrast, and ample whitespace. Do not invent dates, venues, or
institutional logos. Leave editable space for event details.

Prompt 4: Write a short narration script

Write a 45-second narration based only on the approved content.
Use clear, friendly language for undergraduate students.
Keep the main message consistent with the slides and poster.
Do not add new factual claims. Finish with one practical takeaway.

7. Keeping Outputs Consistent

  • Use one content brief: Maintain approved wording for the title, learning objectives, definitions, and key messages.
  • Keep terminology stable: Avoid changing technical terms between slides, posters, and narration.
  • Control versions: Label drafts and approved assets clearly.
  • Check claims across formats: A statistic or statement should not change when repurposed.
  • Match the audience: Keep language and detail level appropriate across all materials.
  • Review visual identity: Check headings, symbols, layout, and tone for consistency.

10. Responsible and Ethical Multimodal AI

  • Verify important information before publishing or submitting it.
  • Respect privacy and avoid uploading confidential documents, recordings, or personal images without authorisation.
  • Use images, music, voices, and other assets only in ways permitted by applicable rights and tool terms.
  • Do not create misleading synthetic media or impersonate real people without appropriate permission.
  • Disclose AI assistance or synthetic content when required or when needed to avoid misleading an audience.
  • Check for stereotypes, accessibility barriers, and misleading visualisations.
  • Follow institutional policies for academic integrity and use of AI-generated work.

11. Integrated Student Project

Task: Build a small learning package on a topic from your engineering discipline using at least three AI productivity modalities or tool categories.

Required deliverables:

  1. Content brief: Topic, audience, purpose, three learning objectives, and verified key points.
  2. Visual asset: A poster or infographic concept.
  3. Presentation: A 5–7 slide outline with speaker notes.
  4. Audio/video asset: A short narration script, captioned audio, storyboard, or video clip.
  5. Prompt record: The prompts used and a brief description of how each was refined.
  6. Quality report: At least five checks covering accuracy, consistency, accessibility, privacy, and rights.

Suggested process: Prepare and verify the content brief first. Reuse it to create each asset. Review every output, correct mismatches, and submit only the approved versions.

Conclusion

Multimodal AI makes it possible to connect text, images, audio, video, and structured data in one productivity workflow. The strongest results come from clear objectives, a shared content brief, carefully sequenced prompts, verification at each stage, and responsible human review. AI can help create multiple formats efficiently, but accuracy, consistency, and ethical use remain essential.
