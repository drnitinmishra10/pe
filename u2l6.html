✉️ 1. Email Generation Prompts

Objective: Draft professional, clear, and action-oriented emails (e.g., project updates, leave requests, escalation notices).

Key Prompt Blueprint

"Act as a professional Corporate Communications Specialist. Write a formal email requesting a 2-day deadline extension for the 'Cloud Deployment Project'.

Context: Unexpected server downtime delayed testing by 48 hours.
Recipient: Project Manager.
Tone: Polite, professional, and solution-focused.
Constraints: Keep under 150 words and include a clear call-to-action."

📄 2. Resume & Cover Letter Prompts

Objective: Generate tailored resume bullet points and cover letters aligned with specific Job Descriptions (JDs).

Key Prompt Blueprint

"Act as a Senior IT Recruiter. Optimize the following resume experience section for a 'Junior Software Engineer' role.

Candidate Experience: Developed a Python script to automate data entry; managed database tables.
Target Job Requirements: Strong Python skills, SQL optimization, workflow automation.
Constraints:
- Write 3 bullet points using the Action Verb + Task + Result framework.
- Highlight quantifiable impact where applicable."

✍️ 3. Essay & Formal Letter Prompts

Objective: Craft well-structured essays or official letters with clear logical flow, arguments, and conclusions.

Key Prompt Blueprint

"Act as an Academic Writer. Draft a 400-word structured analytical essay on 'The Role of AI in Renewable Energy Systems'.

Structure Required:
1. Introduction with a clear thesis statement.
2. Two Body Paragraphs (Focus: Smart Grid Optimization and Predictive Maintenance).
3. Conclusion summarizing key points.
Constraints: Maintain an academic, formal tone; avoid conversational language."

⚡ Framework Summary for Workplace Prompting

Document Type Critical Persona Key Inputs Needed Primary Output Structure
Email Corporate Communicator Recipient, Core Reason, Next Steps Subject Line, Greeting, Body, CTA, Sign-off
Resume / Letter Technical Recruiter / Career Coach Job Description, Existing Experience Action-oriented bullet points, Targeted Cover Letter
Essay Academic / Technical Writer Topic, Target Length, Key Arguments Title, Intro, Body Paragraphs, Conclusion

🎓 Classroom Activity

  1. Find a real entry-level Job Description online for a Software Developer role.
  2. Draft a prompt using the Job Description to generate a tailored 200-word cover letter highlighting your technical skills.
  3. Test the prompt with an LLM and review whether all constraints were followed.

📝 Assignment

  1. Write three complete, ready-to-use prompts for:
    • A formal complaint email regarding defective IT equipment.
    • A professional resume bullet point set for a Data Analyst intern position.
    • An argumentative essay outline on "Ethics in Automated Decision Making".

📌 Lecture Summary

  • Workplace prompting requires precise contextual parameters including audience, tone, and goals.
  • Effective email prompts define recipient dynamics, core message, and specific calls-to-action.
  • Resume and cover letter prompts perform best when aligned directly against specific Job Descriptions.
  • Essay prompts require strict structural outlines to maintain logical coherence and depth.
