🎭 What is a Persona Prompt?

Persona Prompting:
A technique where the AI is instructed to adopt a specific identity, role, expert persona, or voice to shape its knowledge retrieval, tone, and decision-making framework.

Why Use Persona Prompts?

  • Domain Alignment: Tailors jargon and depth (e.g., Senior Software Architect vs. High School Student).
  • Tone Calibration: Adjusts behavior (e.g., Strict Reviewer, Encouraging Tutor, Concise Business Executive).
  • Perspective Simulation: Enables multi-perspective problem evaluation (e.g., Red Team vs. Blue Team security analysis).
Example: "Act as a Senior Database Administrator with 15+ years of SQL optimization experience. Review the following slow query and suggest index adjustments."

📋 Reusable Prompt Templates

A Prompt Template uses placeholder variables to standardize prompt structures for repeated operations across teams or applications.

Anatomy of a Prompt Template

Element Description
Static Context The fixed role, general guidelines, and output structure.
Variables / Dynamic Placeholders Values inserted at runtime, typically wrapped in brackets e.g., [Target Audience], [Input Code].
Constraints & Output Format Enforced rules that remain constant regardless of dynamic input.

Sample Template Structure

"Act as a [ROLE]. Analyze the following [INPUT TYPE] for [TARGET AUDIENCE].

Input Data:
[INSERT DATA HERE]

Rules:
- Keep response under [WORD COUNT] words.
- Present key insights in a [FORMAT]."

⚡ Comparing Fixed Prompts vs Templated Persona Prompts

Feature Fixed / Ad-hoc Prompt Templated Persona Prompt
Reusability One-time use; requires rewriting High; plug-and-play variables
Consistency Variable output quality Standardized, repeatable outputs
Tone Control Often default/neutral Customized to role & audience
Efficiency Slow for repetitive tasks High speed and easy automation

🎓 Classroom Activity

  1. Design a Prompt Template for **Code Review** with variables: [Language], [Code Snippet], and [Focus Area].
  2. Test the template with two different personas: "Strict Security Auditor" vs "Beginner-Friendly Coding Mentor".
  3. Note how the tone and emphasis shift while reviewing the exact same code snippet.

📝 Assignment

  1. Create three distinct reusable prompt templates for common academic workflows (e.g., Research Paper Summarization, Lab Report Feedback, Concept Explanation).
  2. Ensure each template includes clearly marked dynamic placeholders and an assigned persona.

📌 Lecture Summary

  • Prompt templates standardize prompts using parameterized variables for dynamic input.
  • Combining Personas and Templates leads to efficient, highly reliable, and reproducible AI outputs.
