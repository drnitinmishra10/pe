By the end of this lecture, students should be able to:

  • Decompose complex tasks into smaller, manageable subtasks.
  • Design structured prompts for academic and real-world problems.
  • Review intermediate outputs and validate final AI-generated results.

3. Introduction: Why Structure Prompts?

Imagine asking an AI system to develop a complete online shopping website. The task may require requirements analysis, database design, interface development, security planning, testing, and documentation. One broad instruction may not clearly guide every stage.

Opening question: If you ask an AI to develop a complete online shopping website, should it do everything in one instruction? Why or why not?

Prompt engineering involves designing instructions that help an AI system understand the task, constraints, context, and expected output. For complex tasks, organizing the work into stages or levels makes the workflow easier to manage and review.

4. Multi-Step Prompting

4.1 Definition

Multi-step prompting is a technique in which a complex problem is solved through a sequence of related instructions. The result of one step is used as input or context for a later step.

Step 1: Analyze the problem
↓
Step 2: Generate a solution
↓
Step 3: Evaluate the solution
↓
Step 4: Produce the final output

Key idea: Solve the problem in stages rather than expecting one instruction to handle every requirement at once.

4.2 Example: Creating a Study Plan

Single-step prompt:

Create a complete study plan for a first-year engineering student.

This prompt gives little guidance about the student's available time, weak subjects, deadlines, or how the timetable should be checked.

Multi-step prompt sequence:

  1. Identify the student's subjects, available study hours, deadlines, and weak areas.
  2. Prioritize subjects according to difficulty and upcoming assessments.
  3. Create a weekly timetable using the information collected.
  4. Review workload balance and revise the timetable if necessary.
Class discussion: Which approach makes it easier to identify and correct mistakes?

4.3 Prompt Chaining

Prompt chaining connects prompts so that the output of one prompt informs the next prompt. It is one way to implement a multi-step workflow.

Example: Preparing a research paper outline

  1. Identify the research problem.
  2. Develop research questions and objectives based on the problem.
  3. Organize the paper into appropriate sections.
  4. Check that the outline aligns with the research objectives.

Prompt chains may be performed manually or coordinated by software. Important context should be carried forward at each stage.

5. Hierarchical Prompting

5.1 Definition

Hierarchical prompting organizes instructions into levels, moving from a broad objective to major components and then to detailed subtasks. The structure is often tree-like.

Level 1 — Main objective: Develop an online learning platform
↓
Level 2 — Component ALevel 2 — Component B
User managementCourse management
Level 3: Registration and loginLevel 3: Lessons and quizzes

The top level defines the overall goal. The lower levels describe components, subtasks, and specific actions needed to complete the project.

5.2 Three Levels of Hierarchical Planning

  1. Strategic level — What must be achieved?
    Example: Analyze student performance.
  2. Tactical level — Which major components are required?
    Example: Prepare data, calculate indicators, and identify patterns.
  3. Operational level — What specific actions are needed?
    Example: Handle missing values, calculate averages, compare results, and validate findings.

Hierarchical prompting helps keep detailed tasks connected to the overall objective.

6. Multi-Step vs. Hierarchical Prompting

FeatureMulti-Step PromptingHierarchical Prompting
Main focusSequence of actionsLevels of organization
StructureStep 1 → Step 2 → Step 3Goal → Components → Subtasks
Typical workflowSequentialTree-like or layered
Best suited forProcesses with ordered stagesLarge tasks with multiple components
ExampleAnalyze, draft, reviewProject, modules, individual tasks
Remember: The two techniques can be combined. Hierarchical planning defines the subtasks; multi-step prompting can execute each subtask in a suitable sequence.

7. Decomposition, Refinement, and Validation

A reliable workflow for a complex task can follow these steps:

  1. Decompose the main task into smaller subtasks.
  2. Complete each subtask with a clear instruction and expected output.
  3. Combine the outputs while preserving important context.
  4. Check consistency, completeness, and factual support.
  5. Revise errors or missing sections and produce the final result.

Some subtasks can be performed independently, while others depend on the outputs of earlier tasks. Identify those dependencies before execution.

8. Live Demonstration: Student Performance Analysis

Main task: Analyze student marks and recommend academic support. Use synthetic or anonymized data for classroom demonstrations.

Prompt 1 — Understand the data

Inspect the supplied student marks dataset. Identify columns, data types, missing values, and possible data-quality problems. Do not make performance conclusions yet.

Prompt 2 — Analyze performance

Using the validated dataset, calculate subject-wise averages and identify students who may require additional academic support. Explain the criteria used.

Prompt 3 — Recommend interventions

Based on the analysis, suggest appropriate academic interventions. Avoid unsupported assumptions about individual students.

Prompt 4 — Validate the result

Check whether each recommendation is supported by the calculated results. Identify limitations and correct any inconsistencies.
Teaching point: The first prompt prevents premature conclusions. Later prompts use the results of earlier steps, and the final prompt checks whether the recommendations are supported by evidence.

10. Common Mistakes to Avoid

  • Making subtasks too broad or unnecessarily small.
  • Failing to define the expected output format.
  • Losing important context between prompts.
  • Combining outputs without checking consistency.
  • Assuming AI-generated information is automatically correct.
  • Creating hierarchical levels without considering task dependencies.

11. Classroom Activity

Problem: Design an AI-assisted college event management system.

Work in pairs and prepare the following:

  1. Write one main objective for the system.
  2. Identify three or four major components.
  3. List at least two subtasks under each component.
  4. Write a sequence of prompts to plan, implement, and validate one component.

Possible components include event registration, scheduling, notifications, and feedback collection.

12. Review Questions

  1. Define multi-step prompting and give one example.
  2. What is hierarchical prompting? Explain its three levels.
  3. Differentiate between multi-step prompting and hierarchical prompting.
  4. What is prompt chaining?
  5. Why should intermediate and final AI outputs be validated?
  6. How can the two prompting techniques be combined in a software development project?

14. Summary and Conclusion

  • Multi-step prompting organizes a task into a sequence of connected actions.
  • Hierarchical prompting organizes a task into levels, from the main goal to detailed subtasks.
  • Combining the methods can make complex workflows easier to plan, execute, review, and improve.
  • Neither method guarantees correctness; outputs still require suitable validation.
Closing question: If you were building an AI-based medical diagnosis system, which tasks would you organize hierarchically, and which would you execute sequentially?
