3. What Is Prompt Decomposition?

Prompt decomposition is the process of breaking a complex or broad instruction into smaller, clearly defined parts. Each part specifies an element of the task, such as the role, objective, input, decision rules, constraints, or expected output.

Instead of asking an AI to “analyse customer feedback,” a decomposed prompt tells the AI what role to adopt, what to classify, which labels are permitted, how to choose a label, and how to present the result.

Why is it useful?

  • Reduces uncertainty in the instructions.
  • Defines the scope of the task.
  • Improves consistency across similar inputs.
  • Makes errors easier to identify and correct.
  • Supports evaluation because the expected output is explicit.

4. The Task in This Lecture

Given instruction:
“Classify customer feedback into one of three categories: [Pricing, Support, Features]. You are a financial analyst.”

This instruction contains the basic role and task, but it can be improved by clarifying what each category means, how to handle feedback that mentions multiple topics, and what output format is required.

6. Understand the Three Categories

6.1 Pricing

Use Pricing when the main issue is price, cost, billing amount, subscription fee, discount, affordability, or perceived value for money.

Example feedback: “The monthly subscription is too expensive for a small business.”
Category: Pricing
Reason: The customer is concerned about subscription cost.

6.2 Support

Use Support when the main issue concerns customer service, help, complaint handling, response time, troubleshooting, or assistance from the service team.

Example feedback: “I contacted customer care three times but nobody solved my problem.”
Category: Support
Reason: The customer is dissatisfied with the help received.

6.3 Features

Use Features when the main issue concerns product functionality, missing capabilities, usability, performance, integrations, or a request for a new feature.

Example feedback: “Please add an option to export reports to Excel.”
Category: Features
Reason: The customer requests additional product functionality.

7. Complete Decomposed Prompt

You are a financial analyst reviewing customer feedback to identify business issues and opportunities. TASK: Classify each customer feedback statement into exactly one of these categories: 1. Pricing 2. Support 3. Features CATEGORY DEFINITIONS: - Pricing: Cost, price, fees, billing amount, discounts, affordability, or value for money. - Support: Customer service, assistance, complaint handling, response time, or troubleshooting. - Features: Product functionality, missing capabilities, usability, integrations, performance, or requests for new functionality. DECISION RULE: Choose the category that best represents the customer's main concern or request. If a comment mentions more than one topic, select the dominant issue. Do not assign multiple categories. CONSTRAINTS: - Use only the labels Pricing, Support, or Features. - Do not invent information that is not present in the feedback. - If the feedback is unclear, still select the closest category and state briefly that the comment is ambiguous. - Keep the reason concise and based on the customer's words. OUTPUT FORMAT: Return a table with these columns: Customer Feedback | Category | Reason Now classify the following customer feedback: [Insert customer feedback here]

8. Worked Example: Classify Customer Feedback

Customer feedbackCategoryReason
“The annual plan costs more than our budget allows.”PricingThe concern is affordability and cost.
“The support team takes two days to reply.”SupportThe issue is response time.
“I need a dashboard that compares monthly sales.”FeaturesThe customer requests a new capability.
“I was charged twice and cannot get anyone to help me.”SupportThe dominant expressed issue is difficulty getting assistance. Billing could also be relevant, so context may affect the label.
“The product works well, but the premium plan is too costly.”PricingThe main concern is the cost of the plan.
“The app crashes whenever I export a report.”FeaturesThe issue concerns product functionality. If the customer is primarily asking for troubleshooting, Support may be appropriate under a different decision rule.

9. Handling Ambiguous or Mixed Feedback

Some comments contain more than one issue. The prompt should state how the AI should handle these cases.

Mixed comment: “The software is expensive, and the support team is slow.”
Possible labels: Pricing or Support.
Recommended rule: Select the main concern expressed by the customer. If no dominant concern is evident, use a consistent tie-breaking rule or mark the case for human review when the output requirements permit it.
Important limitation: A forced single-label task can lose information when feedback contains multiple distinct issues. If business analysis requires all issues to be captured, use multi-label classification instead. For this exercise, the model must return exactly one of the three requested categories.

10. Prompt Quality Checklist

Before using the prompt, check whether it:

  • Defines the AI's role and objective.
  • Lists all three permitted categories exactly.
  • Explains the meaning of each category.
  • Provides a rule for mixed or ambiguous comments.
  • Specifies a consistent output format.
  • Prevents unsupported assumptions and invented details.
  • Can be tested against examples with known expected labels.

14. Summary

  • Prompt decomposition turns a broad instruction into smaller, explicit parts.
  • A classification prompt should define the role, task, input, categories, decision rules, constraints, and output format.
  • For this task, the only permitted labels are Pricing, Support, and Features.
  • Category definitions and examples make classification decisions easier to apply consistently.
  • Test the prompt with varied examples and review ambiguous cases before relying on results for business decisions.
Exam tip: Prompt decomposition answers the question, “What smaller instructions and rules are needed to make the main task clear, consistent, and verifiable?”
