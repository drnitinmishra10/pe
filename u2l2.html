🔗 Connection with Lecture 1

Recall from Lecture 1:
A useful prompt can be designed using:

Task + Context + Audience + Constraints + Output Format

In this lecture, we go one step further and study how these elements can be organized into a practical prompt structure. A commonly used addition is Role, which can provide useful perspective or expertise when appropriate.

Important:
Not every prompt needs all five or six elements. A simple task may require only a clear instruction, while complex tasks may benefit from additional context, constraints, audience information, role and output requirements.

🧱 The Core Building Blocks of a Prompt

Practical Prompt Framework:

Role + Task + Context + Constraints + Output Format

Audience can be included within the Context or specified separately when it significantly affects the desired response.
Component What It Tells the AI Example Is It Always Required?
1. Role What perspective, professional viewpoint or style should be adopted? "Act as a database instructor..." No
2. Task What should the AI do? "Explain normalization with examples." Usually essential
3. Context What background information is relevant? "The learners are first-year B.Tech students." Depends on the task
4. Constraints What limits, conditions or rules should be followed? "Use simple language and stay under 300 words." Optional but useful
5. Output Format How should the result be presented? "Present the answer as a comparison table." Optional but often useful

1️⃣ Role — Setting the Perspective

Definition:
A Role instruction tells the AI what perspective, professional viewpoint, expertise or communication style to use while performing the task.

Examples

  • "Act as a Python programming instructor."
  • "Act as a technical content editor."
  • "Act as a career counselor for engineering students."
  • "Act as a beginner-friendly mathematics tutor."
Important: A role instruction can influence the way an answer is framed, but it does not give the model real-world credentials or guarantee expert-level correctness.

2️⃣ Task — Defining What to Do

Definition:
The Task is the main action that the AI is expected to perform. It is usually the most important part of the prompt.

Common Task Verbs

  • Explain
  • Summarize
  • Compare
  • Analyze
  • Classify
  • Generate
  • Rewrite
  • Translate
  • Evaluate
  • Design
Example:
Instead of: "Machine Learning"

Write: "Explain the difference between supervised and unsupervised learning."

3️⃣ Context — Providing Background

Definition:
Context provides background information that helps the AI understand the situation, purpose or environment surrounding the task.

Useful Context May Include

  • Target audience
  • Purpose of the task
  • Existing knowledge level
  • Industry or domain
  • Available data
  • Problem background
  • Previous decisions or requirements
Example:
"The audience consists of first-year B.Tech students who have studied basic Python but have no prior knowledge of machine learning."

4️⃣ Constraints — Defining the Boundaries

Definition:
Constraints specify the boundaries, limits or conditions that the AI should follow while completing a task.

Common Constraints

Constraint Type Example
Length "Keep the response within 250 words."
Language "Use simple English suitable for beginners."
Scope "Focus only on supervised learning."
Tone "Use a professional and friendly tone."
Content "Include exactly three examples."

5️⃣ Output Format — Controlling Presentation

Definition:
Output Format describes how the requested information should be organized or presented.

Common Output Formats

  • Bullet points
  • Numbered list
  • Paragraphs
  • Comparison table
  • Step-by-step procedure
  • JSON
  • Code
  • Frequently Asked Questions (FAQ)
Example:
"Present the comparison using a table with columns for Definition, Advantages, Disadvantages and Example."

🧩 Complete Prompt Example

Let's combine the components into one practical prompt.

Role: Act as a Data Science instructor.

Task: Explain the concept of data visualization.

Context: The learners are first-year B.Tech students who understand basic statistics but are new to Data Science.

Constraints: Use simple English, stay within 300 words, and include three practical examples.

Output Format: Use headings followed by bullet points and finish with a short real-world example.
Combined Prompt:

"Act as a Data Science instructor. Explain the concept of data visualization to first-year B.Tech students who understand basic statistics but are new to Data Science. Use simple English, stay within 300 words, and include three practical examples. Use headings followed by bullet points and finish with a short real-world example."

🔍 Deconstructing a Prompt

Prompt engineering becomes easier when we learn to break a large instruction into smaller components.

Prompt Fragment Component Purpose
"Act as a cybersecurity instructor." Role Sets the perspective
"Explain phishing attacks." Task Defines the main action
"The audience is first-year engineering students." Context Defines the learner level
"Use simple language and provide three examples." Constraints Sets boundaries
"Use a table followed by key takeaways." Output Format Controls presentation

Key Idea: The purpose of structure is not to make prompts unnecessarily long. The purpose is to make the user's intention easier for the AI to interpret.

📈 What Happens When We Add Components?

Prompt Version What It Contains Expected Improvement
Version 1 "Explain AI." Very broad response
Version 2 Task + Audience Better level and focus
Version 3 Task + Context + Audience + Constraints More controlled response
Version 4 Role + Task + Context + Constraints + Output Format More structured and task-specific response

🚦 Essential vs Optional Components

Do not memorize the framework as a rigid rule.

The exact structure depends on the task.
Task Likely Minimum Requirement
Simple factual question Clear Task
Educational explanation Task + Audience/Context
Report generation Task + Context + Constraints + Output Format
Professional analysis Role + Task + Context + Constraints + Output Format
Highly complex workflow Detailed context + multiple requirements + explicit output structure

🎓 Classroom Activity

  1. Start with the weak prompt: "Write a project proposal on IoT."
  2. Ask students to identify what information is missing.
  3. Add the components one by one: Role → Task → Context → Constraints → Output Format.
  4. Create a final structured prompt as a class.
  5. Run both the original and improved prompts in an LLM tool.
  6. Compare the outputs and identify which prompt elements changed the result.

📌 Lecture Summary

  • A prompt can be designed using several complementary components.
  • Task defines what the AI should do.
  • Role can provide a useful perspective when appropriate.
  • Context supplies relevant background information.
  • Constraints define boundaries such as length, scope or tone.
  • Output Format describes how the result should be organized.
  • Not every prompt requires every component. The best structure depends on the task.
  • Good prompt writing is an iterative process: Write → Test → Evaluate → Refine.
