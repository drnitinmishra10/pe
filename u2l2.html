🧱 The 5 Core Building Blocks of a Prompt

Anatomy of a Prompt:
A comprehensive prompt combines Role, Task, Context, Constraints, and Output Format to provide unambiguous instruction to an LLM.
Component Description Example Fragment
1. Role Sets the perspective, authority, or expertise the AI should adopt. "Act as a Senior Cyber Security Analyst..."
2. Task The primary action or objective the AI must perform. "...evaluate the following code snippet for vulnerabilities..."
3. Context Background information or target audience details necessary to frame the work. "...for a banking web application that processes user transactions..."
4. Constraints Boundaries, limitations, or rules (word limits, prohibited topics, tone). "...do not use jargon, keep under 200 words, and highlight top 3 risks..."
5. Output Format The structure of the generated response (table, Markdown, bullet points, JSON). "...present the findings in a Markdown table with columns: Risk, Severity, and Mitigation."

⚡ Blueprint vs Complete Prompt

Anatomy in Action:

  • Role: Act as a Technical Career Mentor.
  • Task: Review the provided resume summary and suggest improvements.
  • Context: The candidate is a final-year CS student applying for software development roles.
  • Constraints: Limit feedback to 4 actionable bullet points; avoid harsh criticism.
  • Output Format: Format as a numbered list with bold category headers.
Combined Complete Prompt:
"Act as a Technical Career Mentor. Review the provided resume summary for a final-year CS student applying for software development roles. Suggest improvements by limiting feedback to 4 actionable points without using overly harsh criticism. Format the output as a numbered list with bold category headers."

📈 Why Structural Components Matter

  • Role: Adjusts tone, vocabulary, and depth of technical detail.
  • Task: Keeps the AI focused on a single clear goal.
  • Context: Eliminates guesswork and assumptions by the model.
  • Constraints: Prevents overly verbose, irrelevant, or unsafe responses.
  • Output Format: Makes the output immediately usable without manual reformatting.

🎓 Classroom Activity

  1. Take the weak instruction: "Write a project proposal on IoT."
  2. In groups of two, assign all 5 structural components (Role, Task, Context, Constraints, Output Format) to upgrade it.
  3. Run the weak vs. upgraded prompt in an LLM and evaluate the output quality.

📝 Assignment

  1. Select two distinct domains (e.g., Healthcare, Digital Marketing, Finance).
  2. Draft a fully-structured prompt for each domain, clearly tagging the [Role], [Task], [Context], [Constraints], and [Output Format].

📌 Lecture Summary

  • Prompts perform best when constructed using modular structural elements.
  • Role establishes context and authority; Task specifies the core action.
  • Context and Constraints refine boundaries and ensure precision.
  • Output Format guarantees the response is delivered in the desired structure.

❓ Review Questions

  2. How does assigning a 'Role' change the output generated by an LLM?
  3. Why are constraints essential when asking LLMs to generate text?
  4. Give an example of an output format specification and explain its utility.
