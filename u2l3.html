📂 Classification of Prompts

Prompt Categorization:
Prompts can be categorized based on how they guide the model's reasoning—ranging from exploratory and open choices to highly constrained, objective execution.

1. Open-ended Prompts

Designed to encourage creative exploration, brainstorming, and generative expansion without strict constraints.

  • Purpose: Idea generation, creative writing, multi-angle discussions.
  • Example: "What are some innovative ways artificial intelligence can transform urban public transport?"

2. Close-ended Prompts

Targeted prompts designed to produce direct, specific, and bounded responses (e.g., binary choices, short answers, or facts).

  • Purpose: Fact verification, quick queries, structural categorization.
  • Example: "Is Python an interpreted or compiled programming language? Answer in one word."

3. Instruction Prompts

Explicit, command-driven prompts that guide the model to perform specific tasks step-by-step or follow rigorous guidelines.

  • Purpose: Data conversion, code refactoring, summarization, translation.
  • Example: "Convert the following paragraph into three bullet points highlighting key metrics."

4. Question Prompts

Framed specifically around analytical, reflective, or technical questions to test or extract conceptual clarity.

  • Purpose: Concept verification, step-by-step troubleshooting, technical explanations.
  • Example: "Why does time complexity increase from O(n) to O(n²) in nested loops?"

⚡ Comparative Analysis of Prompt Types

Prompt Type Primary Objective Flexibility Level Best Suited For
Open-ended Exploration & Generative Thought High Brainstorming, essays, creative tasks
Close-ended Precision & Fact Retrieval Very Low Multiple choice, true/false, classification
Instruction Action Execution Medium Formatting, code generation, summarization
Question Conceptual Explanation Medium-High Troubleshooting, learning concepts, analysis

🎓 Classroom Activity

  1. Select a central topic: "Data Privacy".
  2. Draft four distinct prompts on this topic—one Open-ended, one Close-ended, one Instruction, and one Question Prompt.
  3. Submit all four to an LLM and compare the structural differences in responses.

📝 Assignment

  1. Identify a software development or engineering problem.
  2. Write a 2-page document containing two Instruction Prompts and two Question Prompts designed to help debug and document that problem.

📌 Lecture Summary

  • Prompts are categorized based on their intent, level of constraint, and output expectations.
  • Open-ended prompts foster creativity, while close-ended prompts enforce strict precision.
  • Instruction prompts direct operational execution, whereas question prompts focus on conceptual explanation.
  • Selecting the correct prompt type significantly improves response utility and reduces iteration time.

❓ Review Questions

  2. When would you prefer an Instruction Prompt over a Question Prompt?
  3. How does changing a prompt from open-ended to close-ended alter an LLM's response behavior?
